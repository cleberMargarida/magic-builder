**MagicBuilder** is a lightweight and powerful .NET library that simplifies the creation of builder objects using a fluent, customizable API.

Built on **.NET Standard 2.0**, it's compatible with:

- **.NET Core**: 2.0, 2.1, 3.0, 3.1  
- **.NET**: 5, 6, 7, 8, 9, 10  
- Any other platform supporting **.NET Standard 2.0**

## Features

- ✨ Fluent API
- ⚙️ Source generator
- 🚀 No reflection

## Installation

To install MagicBuilder, you can use the NuGet Package Manager:
```bash
PM> Install-Package MagicBuilder
```
## Usage

Here is a simple example of how to use MagicBuilder:

Considering `Person` to generate a builder:
```csharp
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
}
```

1. Instructs the generator to create a builder for the current assembly:
```csharp
[assembly: GenerateBuilder(typeof(Person))]
```

2. Then, you can use the generated builder like this:
```csharp
var person = Builder.Create<Person>()
                    .WithAge(21)
                    .WithName("name")
                    .Build();
```
Behind the scenes extension method's like this are generated:
```csharp
// <auto-generated/>
using System;

namespace MagicBuilder {

    public static class PersonBuilderExtensions {

        public static Builder<Person> WithName(this Builder<Person> builder, string value) 
            => builder.Apply(obj => obj.Name = value);

        public static Builder<Person> WithAge(this Builder<Person> builder, int value) 
            => builder.Apply(obj => obj.Age = value);
}
```
It supports: `class`'s, `record`'s, and `struct`'s.
